# CRM AI First — Squaad

CRM completo com Inteligência Artificial para gestão de vendas, desenvolvido por **Carlos Eduardo / Squaad**.

## O que o sistema faz

- **Funil de vendas** visual, com arrastar e soltar
- **WhatsApp integrado** — envie e receba mensagens direto do CRM
- **Agente IA de Vendas** — responde leads automaticamente 24h por dia, qualifica, agenda reuniões e faz follow-up sozinho
- **Telefonia VoIP** com transcrição das chamadas em tempo real
- **Análise por IA** de leads, chamadas e entrevistas
- **Marketing** — gerador de UTM, integração com Meta Ads e criação de criativos com IA
- **Gestão de entrevistas** com link automático de Google Meet
- **Dashboard** com indicadores de vendas

## Tecnologias

- Vite + React + TypeScript
- shadcn/ui + Tailwind CSS
- Supabase (banco de dados, autenticação e funções do servidor)
- OpenAI e Anthropic Claude (inteligência artificial)

## Como rodar o projeto

```sh
# 1. Instalar as dependências
npm install

# 2. Iniciar o sistema
npm run dev
```

Depois é só abrir o navegador em **localhost:8080**.

> Antes de rodar pela primeira vez, é preciso configurar o arquivo `.env` com os dados do Supabase. Veja o `.env.example` como referência.
